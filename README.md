# 文章読み上げ

ブラウザ標準の Web Speech API（`SpeechSynthesis`）を使用して、日本語の文章を読み上げるシンプルな静的Webアプリです。外部API、APIキー、Node.js、ビルド作業は必要ありません。

## 使い方

1. `index.html` を Chrome、Edge、Safari などの対応ブラウザで開きます。
2. 大きな入力欄へ読み上げたい文章を入力、または貼り付けます。
3. 必要に応じて「音声」と「読み上げ速度」を選びます。
4. 「読み上げ」を押すと再生が始まります。
5. 再生中は「一時停止」「再開」「停止」を利用できます。

「読み上げ」をもう一度押すと、現在の再生を停止し、入力欄にある文章を先頭から読み上げます。長い文章は文末や改行を目安に分割し、順番に再生します。

「現在読み上げ中」には入力文章の改行が反映され、ブラウザから読み上げ位置を取得できる場合は、現在読んでいる語句が黄色でハイライトされます。

「クリップボードから読み上げ」を押すと、以前の文章と読み上げをクリアしてから、コピーしてある文章を入力欄へ取り込み、すぐに読み上げます。貼り付けた文章に含まれる絵文字と、何も書かれていない空行（空白やタブだけの行を含む）は自動的に削除されます。ブラウザからクリップボードの読み取り許可を求められる場合があります。

許可確認を表示せずに利用するには、入力欄を選択して `Ctrl + V`（スマートフォンでは長押しして「貼り付け」）を実行してください。以前の文章が自動的にクリアされ、絵文字と空行を削除した文章だけをすぐに読み上げます。

初期設定は「Microsoft 七海」（利用可能な場合）と2.0倍速です。七海が利用できない環境では、既定の日本語音声などが自動的に選択されます。

## ローカルでの起動

ダウンロードしたフォルダー内の `index.html` をダブルクリックするだけで使用できます。Webサーバーの起動は不要です。

## 公開方法

このリポジトリの以下のファイルをそのまま静的サイトとして公開できます。

- `index.html`
- `style.css`
- `script.js`

GitHub Pagesではリポジトリのルートを公開元に設定してください。Vercelなどではフレームワークを選ばず、静的サイトとしてデプロイできます。

## 対応環境と注意事項

- Web Speech API の `SpeechSynthesis` に対応した最新の Chrome、Edge、Safari などを推奨します。
- 利用できる音声はOSとブラウザによって異なります。日本語音声がインストールされていない環境では、日本語以外の音声だけが表示される場合があります。
- 「オンライン」と表示される音声は、OSやブラウザの仕様によりインターネット接続を必要とする場合があります。このアプリ自体は外部APIへ接続しません。
- ブラウザや端末によって読み上げ方、発音、利用できる速度には差があります。
- クリップボードの自動読み取りはブラウザのセキュリティ制限を受けます。許可ダイアログをWebアプリ側から省略することはできません。GitHub PagesやVercelなどのHTTPS環境、またはlocalhostでの利用を推奨します。`index.html`を直接開いて毎回確認される場合は、入力欄への `Ctrl + V` を利用してください。
